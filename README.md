# SONG DIRECTION SYSTEM BUILDER

JACKPOT031 SONG DIRECTION SYSTEM v2.2 を母型にした、ブラウザだけで動く制作思想ジェネレーターです。

## できること

A/B/C/Dの設問に答えることで、自分専用の `SONG DIRECTION SYSTEM.md` を生成できます。

- QUICK MODE: 17問。短時間で実用的な制作ルールを作成
- DEEP MODE: 分岐式。制作思想、物語、映像、声、音、Suno実装、More Options、レビューまで詳細に設計
- v0.5では「構成 / 感情 / 情景 / 物語性 / 完成感 / 起伏 / 現実感 / ボーカル明瞭度」を独立軸として選択可能
- 回答した制作軸を勝手に連動させない設計
- 日常・現実寄りの作品が不要に幻想化していないかQA
- 改善目的の修正と、一変数テストによる原因検証を区別
- 回答内容はブラウザ内で処理
- 生成MDを保存可能
- Styles / Exclude はカンマ区切り形式に対応
- PRIMARY / EXPERIMENTAL / WILD CARD / DRAFT CHECK に対応
- More Options / Generation Stamp / 自動補正ルールに対応

## 使い方

GitHub Pagesで公開したページを開いて、そのまま使えます。

QUICKは手軽に、DEEPはより細かく自分の制作思想を設計できます。

## Privacy

このBuilderは静的HTMLとして動作し、設問への回答や生成内容を外部サーバーへ送信するための独自通信処理は含めていません。保存状態はブラウザ側のストレージを利用します。
